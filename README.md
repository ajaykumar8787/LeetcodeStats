# LeetCode Stats Fetcher (LeetMetrics)

A simple, fast, and responsive web application that fetches and displays real-time LeetCode problem-solving statistics for any user.

## Features
- Search for any LeetCode username.
- Displays Total Solved, Easy, Medium, and Hard counts.
- Clean and modern circular UI.
- Fully frontend-based (No backend setup required).

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- API: [Alfa LeetCode API](https://github.com/alfa-coder/alfa-leetcode-api)
